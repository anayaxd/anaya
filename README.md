### 🛡️ How I Secure Products

<table>
  <tr>
    <td width="33%" valign="top">
      <h4>🔍 Identify</h4>
      Threat modeling, secure design reviews, code review, and hands-on testing of web apps and APIs to surface weaknesses early.
    </td>
    <td width="33%" valign="top">
      <h4>🧯 Mitigate</h4>
      Risk-based triage, clear remediation guidance, and working side by side with engineers until every fix is verified.
    </td>
    <td width="33%" valign="top">
      <h4>🔁 Prevent</h4>
      Security checks built into the pipeline — SAST, SCA, secret scanning, and IaC scanning — so regressions never reach production.
    </td>
  </tr>
